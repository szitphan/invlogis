Duyệt mẫu ghép 14 component theo quy tắc 4 nhóm

Bộ thử Ant Design · tiếp theo trang duyệt Button. 138 mẫu ghép trên 14 trang Figma (Input → Sidebar) đã được em xếp nhóm. Bạn duyệt từng dòng; dòng nào sai nhóm thì bấm nhóm đúng. Duyệt xong em mới sửa Figma và spec, nên ảnh trên trang này là hình hiện tại; cột bên phải ghi mẫu sẽ đi đâu.

Kết quả xếp nhóm


Phần lớn mẫu ghép đã trùng biến thể hoặc thuộc tính có sẵn (nhóm 4), hoặc là cách ghép nhiều component (nhóm 3). Chỉ 6 mẫu cần thuộc tính mới, 3 mẫu chuyển sang component đợt tới.





Thay đổi trên component gốc


Nhóm 1 thêm thuộc tính bật tắt vào set có sẵn, không thêm trục biến thể. Nhóm 2 chuyển sang component trong danh sách 28 đợt tới.




Input · Phần đầu (bật tắt + chọn nội dung): chữ tiền tố "https://" hoặc Select nhỏ (mã quốc gia). ng-zorro nzAddOnBefore. Từ web-07, web-18.


Input · Phím tắt (bật tắt, instance Kbd): ô tìm có "Ctrl K", giống Button. Từ kbd-03.


Input · Nhãn trong ô (bật tắt): nhãn nhỏ nằm trong ô, ô cao hơn. Từ web-25 — xem câu hỏi 1.


Select · Dòng phụ (bật tắt + chữ): ô hiện 2 dòng (tên + SĐT), đi cùng Đầu=Ảnh. Từ web-13.


Breadcrumb · Rút gọn (bật tắt): thay các mục giữa bằng "…" có menu. Từ web-02.


→ Input OTP (đợt tới): web-17 mã OTP 4 ô.


→ Toggle Group (đợt tới, nz-radio-group kiểu nút): radio btn-o, btn-s; bỏ set Radio nút — xem câu hỏi 2.
