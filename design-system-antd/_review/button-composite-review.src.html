Quy tắc 4 nhóm


Mẫu ghép cũ là các component riêng dựng từ instance Button. Cách đó làm thư viện phình ra và dev không biết mẫu ứng với API nào của ng-zorro. Quy tắc mới: mẫu nào chỉ thêm một phần nhỏ vào nút thì thành thuộc tính bật tắt của set Button (không thêm trục biến thể, set vẫn 288 tổ hợp); mẫu nào có cấu trúc riêng thì thành component riêng có biến thể.





Từng mẫu: trước và sau ảnh chụp từ Figma


Ảnh Trước = component mẫu ghép cũ. Ảnh Sau = thẻ trong khung "Ví dụ đã chốt" sau khi đổi sang instance của set mới. Dòng có nhãn đỏ Khác hình là chỗ hình đã đổi so với bản bạn duyệt trước, cần xem kỹ.
