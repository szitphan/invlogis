## Getting started — nội dung (diễn giải)
Welcome to Untitled UI (2195-443663): kit ra mắt 2021; có bản Untitled UI React (Tailwind CSS + React Aria) đồng bộ với Figma. Quy trình gợi ý: nhân bản file → thay branding (logo, biến màu, typeface) → dùng section/page example dựng sẵn → xoá phần không dùng. Đã refactor theo Figma mới: color variables (dark mode), spacing, radius, typography, effect variables, Auto Layout 5.0, min/max width, wrap.
Getting up and running: kit dùng mạnh components, Auto Layout, interactive components, variants. File >10.000 component/variant; Figma giới hạn bộ nhớ 2GB/tab → nên chuyển trang example (Marketing website examples, Application examples, ~40% dung lượng) sang file riêng; có thể xoá trang ví dụ dark mode (chỉ là bản sao light với mode Dark để minh hoạ variables); xoá component không dùng. Font mặc định Inter (miễn phí, Rasmus Andersson, 9 độ đậm + italic + variable font). Dùng như library: Publish trong Libraries modal (⌥3), bật "Add to file" ở dự án khác; library là "nguồn sự thật"; còn có thư viện "Untitled UI Icons – PRO".
Split up the file into multiple libraries (2818-377803): 2 cách dùng — nhân bản cho từng dự án rồi xoá bớt, hoặc giữ nguyên và tuỳ biến. Có thể tách thành nhiều library (gợi ý: Main = styles + foundations + base components/assets; Marketing components; Application components; Page examples) bằng "move published components"; lợi ích: nhẹ hơn, publish độc lập, tải nhanh. Họ khuyên đơn giản là xoá component không cần. Cảnh báo "ghost layers" khi move component → chạy script "Compute publish statuses of soft deleted components" định kỳ.
How to master variants / How to master Auto Layout: hướng dẫn kỹ năng Figma chung — chưa đọc chi tiết (không chứa token).
⚠ Hướng dẫn đổi màu brand: không thấy ở Getting started; xem Notes của trang Colors.
