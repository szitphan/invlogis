## Notes and documentation — trang Colors (6721-163832), luật dùng (diễn giải)
- Bảng màu đơn giản cần: neutral, brand, accent và màu phản hồi (xanh = thành công, đỏ = lỗi), nhất là khi có form.
- Neutral (xám): nền tảng; chữ, form field, nền, divider thường là xám. Brand: dùng cho mọi phần tử tương tác (button, link, input…), tạo cảm giác chung; có thể có nhiều primary nhưng bắt đầu với 1. Accent: màu phụ để gây chú ý/hỗ trợ brand, hợp cho label và badge. Feedback: error = trạng thái lỗi và hành động "destructive" (xoá); warning = hành động có thể nguy hiểm/"on-hold", dùng trong xác nhận; success = hành động tích cực/xu hướng tốt; nếu primary là xanh lá thì nên chọn sắc khác cho success.
- Chọn thêm màu: dùng generator làm cho Tailwind (8–12 sắc mỗi màu): uicolors.app, tailwindshades.com, tints.dev, tailcolor.com.
- Định nghĩa hệ màu trước khi thiết kế; đặt tên theo token (neutral-300, brand-600…) thay vì hex rời. Không cần 50 sắc xám — 8–12 sắc, dùng nhất quán: vd luôn neutral-300 cho viền input field, neutral-200 cho divider.
- WCAG 2.2: Level A <4.5:1 (không dùng cho chữ; bỏ qua cho trang trí); Level AA ≥4.5:1 (tối thiểu cho UI quan trọng: chữ, button, form — nên là mặc định); Level AAA ≥7:1 (nice-to-have). Giữ ≥4.5:1 cho mọi phần tử quan trọng. Kiểm bằng WebAIM hoặc plugin Figma "Contrast".
- Đổi bảng màu: quản lý bằng variables (không dùng styles); primitives là "nguồn sự thật", mọi biến màu (và spacing, radius) tham chiếu primitives. Bước: mở Local variables → collection _Primitives → sửa giá trị (vd Brand/500 9E77ED) → làm cho mọi bậc một lượt → cập nhật biến shadow nếu cần (shadow dùng đen + alpha riêng, phải sửa tay).
- ★ ĐỔI MÀU BRAND: chỉ cần đổi các biến "brand" trong _Primitives (thay vì đổi từng component) → mọi chỗ dùng tím tự cập nhật. Có bài hướng dẫn tạo palette trên blog Untitled UI.
- Đổi dải xám: cách tương tự — đổi các biến "neutral" trong _Primitives, hoặc chỉnh hue/saturation trong HSL picker; có thể dùng xám Tailwind khác (Slate, Gray, Zinc…).
- Lịch sử: v5.0 xám hơi xanh ("cool", hợp B2B/SaaS, kiểu Stripe); v6.0 xám "flat" ít bão hoà; v8.0 chuyển toàn bộ sang màu Tailwind CSS, xám mặc định = neutral (hoàn toàn khử bão hoà). Untitled UI React bỏ 436 biến màu thừa nhờ palette gốc của Tailwind v4.2: theme 65KB → 45KB, 1.093 → 657 biến CSS (−40%).

## Gradients (frame 1525-272676) — component _Swatch base gradient (280×200, radius 12, viền 1px #000 10%)
