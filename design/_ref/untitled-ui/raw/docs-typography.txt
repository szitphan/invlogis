Typography

For long-form content like articles or documentation, use our typography styles to ensure consistent formatting. These styles extend the default @tailwindcss/typography plugin.

Installation

In order to use the typography styles, you need to install the official Tailwind CSS Typography plugin and create a custom typography styles file as shows below:

Install the typography plugin
Simply install the official Tailwind CSS Typography plugin with your favorite package manager:
bun
npm
yarn

```
bun add @tailwindcss/typography
```

Create custom typography styles

Import the typography styles
Now, in your globals.css file, load the typography plugin and import the typography.css file:

```
@import "tailwindcss";
@import "./typography.css";

@plugin "@tailwindcss/typography";
```

Use the typography styles
And finally, add the prose class to your content:

```

Heading level 1

Lorem ipsum dolor sit amet, consectetur adipiscing elit. Donec ullamcorper mattis lorem non. Ultrices praesent amet ipsum justo massa.

Lorem ipsum dolor sit amet, consectetur adipiscing elit. Donec ullamcorper mattis lorem non. Ultrices praesent amet ipsum justo massa.

```

FAQs
Please refer to our frequently asked questions page for more.

Do I need these steps if I set up my project with the CLI?
Usually not. npx untitledui@latest init copies typography.css into your styles folder along with a globals.css that imports it and loads @tailwindcss/typography, and installs the plugin if it's missing. Follow the steps above if you set up your project another way.

How do I exclude part of the content from the typography styles?
Add the not-prose class to that element. Every rule in typography.css skips elements with not-prose and their children, which is useful for embedding components like buttons or cards inside long-form content.

How do I make the text larger on bigger screens?
Add md:prose-lg next to prose. From the md breakpoint (768px) up, the base font size increases to text-lg, and headings and spacing scale up to match.

Which quote styles are available?
By default, blockquotes have a left border. Add prose-centered-quote to center quotes and remove the border, or prose-minimal-quote to remove the border and keep the text left-aligned. Both classes go on the same element as prose.

Does the typography work in dark mode?
Yes. The --tw-prose-* color variables point to Untitled UI's semantic color variables such as --color-text-primary, --color-text-tertiary and --color-border-secondary, which theme.css redefines for dark mode.

How do I change the text colors?
Edit the --tw-prose-* variables at the top of typography.css. For example, --tw-prose-body sets the body text color and --tw-prose-headings the heading color. Point them at any color variable from your theme.
